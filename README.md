# ✨ Happy Birthday, Linh! 🎂

A simple, premium, and deeply emotional digital birthday experience created for **Linh**, built with **React** + **Vite**.

---

## 🌟 How to Run & Preview

### 1. Development Server
Start the local development server:
```bash
npm run dev
```
Open **`http://localhost:3000`** in your browser.

### 2. Production Build & Preview
To build and preview the optimized production version:
```bash
npm run build
npm run preview
```

The production-ready standalone build is located in the [`dist/`](file:///Users/mithumohan/Downloads/linh%20birthday/dist/) directory!

## 🌸 Aesthetic & Theme Direction

- **Understated Luxury:** Replaced harsh neon lighting and flashy glows with warm candlelight amber, dusty blush rose, soft champagne gold, and rich midnight plum tones.
- **Natural Interaction:** Removed desktop cursor trails for a clean, distraction-free browsing experience.
- **Stationery & Parchment:** Handwritten letter section styled like a fine vintage letter with an antique garnet wax seal bearing the initial **“L”**.
- **Natural Starlight:** Background canvas renders serene, natural starlight rather than vibrant neon particles.
- **Satin & Matte Glassmorphism:** Clean, refined matte glass cards with subtle elevation and soft organic shadows.

## 🎨 Interactive Gallery Features

- **Polaroid Styling:** Soft white margins, authentic washi tape, and realistic tilt angles.
- **Vibe Filter Pills:** Quickly filter by *All*, *Elegance*, *Childhood*, or *Aesthetic*.
- **Interactive Lightbox:** Full high-resolution modal zoom with keyboard controls (`←` / `→` / `Esc`), previous/next navigation buttons, and touch swipe gestures on mobile.
- **Heart Reaction Badge:** Tap the ❤️ button inside the lightbox or on the cards to leave love reactions for each memory!
